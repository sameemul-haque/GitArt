    Share your font

    1. Fork GitArt and click Create fork. Skip this if you already have a fork.
    2. Come back here and click Continue to GitHub. Your font file opens already filled in.
    3. Paste the font into the empty file (it is already copied).
    4. Click Commit changes… and then Propose changes.
    5. Click Create pull request.

    Everything happens on the GitHub website, so you don't need git. Once it's reviewed and merged, your font shows up for everyone as .
